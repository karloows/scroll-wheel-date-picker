# Example for Scroll Wheel Date Picker

This example app is the quickest way to compare the package's two wheel styles
and their overlay options in a real Flutter app.

## Run the example

From this `example/` directory:

```bash
fvm flutter pub get
fvm flutter run
```

## What to check

- The flat picker is the main showcase and should render without curve
  perspective by default.
- The curve picker should still keep its perspective effect.
- Overlay variants such as `holo`, `highlight`, and `line` should match the
  package README demos.

For package usage, theming options, and API examples, see the root
[`README.md`](../README.md).
